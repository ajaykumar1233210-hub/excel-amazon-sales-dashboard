# Amazon Sales Dashboard (Excel)

## Objective
Analyse Amazon order data to find top revenue categories and delivery problems.

## Tools Used
Excel: Pivot Tables, Charts, Slicers, XLOOKUP

## What I Did
- Analysed 1,000 orders (about $35K order value)
- Built 6 charts and interactive slicers
- Used XLOOKUP to link customer and product master sheets

## Key Findings
- Electronics is the top revenue category
- North region has the highest cancellation rate (40%)
- Only 11 orders were delivered within 2 days

## Recommendation
Improve delivery performance, especially in the North region, to reduce cancellations.
